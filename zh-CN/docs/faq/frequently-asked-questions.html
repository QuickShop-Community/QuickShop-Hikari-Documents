常见问题

我能创建同时收购与出售物品的商店吗？​

不可以。 一个商店能出售或收购，但无法同时进行。 不过你可以用一个大型箱子创建两个商店，一个收购，一个出售。

我能使用实体经济吗（例如用钻石作为货币）？​

不可以。 我们也不会考虑添加。 不过你可以使用支持实体经济的插件。

创建商店时无响应。 这插件坏了吗？​

有些插件可能会阻止创建商店，最常见的就是保护类插件。 你可以在配置文本里禁用 shop.protection-checking 绕过这个检查。

怎么创建一份卖多个物品的商店？​

只需这样做：

  1. 在 config.yml 设置“allolw-stacks”为 true，然后重载插件。
  2. 给予对应玩家（或你自己）quickshop.create.stacks 权限。
  3. 手持物品创建商店时，其数量会被识别为一份商品的出售数量。

我能创建超出原版堆叠限制的商店吗？​

可以。 只需在 config.yml 中启用 custom-item-stacksize 选项，重载插件即可。 之后，就可以输入“/quickshop stack”命令

非保护类插件阻止或破坏了我的商店。 为什么？​

QuickShop 会通过虚拟的 BlockBreakEvent 检查你是否可以在对应区域内建造。 部分插件可能会介入取消这个事件。 可以试试用保护监听器过滤选项解决这个冲突问题。

我如何从 H2 数据库迁移到 MySQL 或 MariaDB（或者反过来）？​

见此

插件报错 NoClassDefFoundError 或 NoSuchMethodError。 为什么？​

这可能是因为不兼容插件或 QuickShop 的 JAR 本体损坏导致的。 更新 QuickShop，然后测试只安装 QuickShop 和必要依赖时能否复现这个问题。 如果还是有问题，那么请考虑在 Github 上反馈。

如何修改或删除某些消息文本？​

覆盖 OTA 翻译

你可以添加对 xxx 的支持吗？​

可能会。 若有需要请前往 Github 反馈。

为什么 QuickShop 在我安装了 Vault 的情况下还是无法启动？​

Vault 不是经济插件；它只是一个经济 API。 请再安装一个支持 Vault 的经济插件。

为什么它不能在 1.7-1.19 上使用？​

请见“测试支持的 Minecraft 版本”。 最新版本只支持 1.20 之后的版本。

有没有已知的兼容性问题？​

部分插件可能不兼容 QuickShop，而且一般我们没有办法解决。

BungeeCord 聊天插件​

大部分 BungeeCord 的聊天插件都不兼容 QuickShop。
但你可以在发布页下载 Compact-BungeeCord 兼容附属。

混合端​

（诸如 Mohist、Arclight、Magma 以及 CatServer）混合端都不完全兼容 QuickShop-Hikari。
部分功能可能无法在这类核心上正常生效，且有可能导致错误或非预期行为。 如果你选择在混合端上使用 QuickShop-Hikari，你需要自行承担风险，自行解决出现的任何问题。

如何支持项目？​

你可以通过 Github Sponsors 或远远的爱发电 支持 QuickShop-Hikari
