商店功能

所有与 QuickShop 有关的功能

📄️ 系统商店（无限商店）

QuickShop 支持您将商店设置为“系统商店”，从而创建一个无限制库存（出售）或无限容量（收购）的商店。

📄️ 商店分成

商店分成功能允许你将商店赚取的资金以不同的比例分配给多个玩家。

📄️ 黑名单系统

服务器管理员可以禁止在某些世界创建商店，或禁止某些物品的出售 / 收购

📄️ 悬浮物

QuickShop 提供了一个很酷的功能，让玩家识别商店物品。

📄️ Shop History

商店历史允许玩家查看商店的交易记录。

📄️ 商店权限独立控制

QuickShop-Hikari提供了一个系统来控制每个商店的权限。

📄️ 价格限制

QuickShop 提供了一个允许你指定物品最低与最高价的机制。

📄️ Protection Checker

QuickShop use a util called Protection Checker to prevent players create shops at their had no build access positions (e.g Spawn).

📄️ 商店保护

Player Protection

📄️ Ranks

QuickShop provides a ranks system to allow control the maximum shops that player can own.

📄️ 批量移除商店

如果您有大量商店需要移除，以下方法可以帮您很快完成。

📄️ 创建与购买

本章节将会指导你如何创建与购买快捷商店。

📄️ Shop Blocks

Not only Chests, but also all Containers all supported used for QuickShop containers!

📄️ Shop Fees

QuickShop allow server administrator setup the shops fees for creating, changing prices.

📄️ Shop History

This wiki images may use non-English locale.

📄️ Shop Purger

Shop Purger allow server administrator purge the shops if the player in idle or banned.

📄️ Shop Search

QuickShop have a built-in shop searcher will allow you search the shops on your server without load any chunks.

📄️ Sign Material

By default, QuickShop-Hikari uses the default brand material from the configuration file, but you can modify it to other brands for your store with the command.

📄️ 堆叠商店

QuickShop allow you sell/buy multiple item in bundles.

📄️ Suggest Price

This feature provides your players with price suggestions for items of interest on your server by command /quickshop suggestprice.
