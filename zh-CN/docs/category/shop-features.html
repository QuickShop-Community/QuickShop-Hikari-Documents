Shop Features

All features related to a quickshop.

📄️系统商店（无限商店）

QuickShop 支持您将商店设置为“系统商店”，从而创建一个无限制库存（出售）或无限容量（收购）的商店。

📄️商店分成

商店分成功能允许你将商店赚取的资金以不同的比例分配给多个玩家。

📄️黑名单系统

服务器管理员可以控制在哪里创建什么类型的商店。

📄️店员（控制面板）

店员管理

📄️商店控制面板（菜单）

商店控制面板玩家通过菜单界面而非聊天栏管理商店。

📄️商店控制面板

商店控制面板允许玩家安全方便地管理自己的商店。

📄️Shop Display System

QuickShop can display the item being bought or sold directly above a shop container. This makes shops easier to identify without requiring players to read the shop sign or open the shop interface.

📄️商店权限独立控制

QuickShop-Hikari 提供了一个系统，可用于单独控制每个商店的权限。

📄️价格限制

QuickShop 的价格限制功能允许你设置服务器上某个物品的最高与最低价格。

📄️保护检查

QuickShop 会用到一个 Protection Checker 的机制阻止玩家在没有权限的地方（例如主城）创建商店。

📄️商店保护

QuickShop-Hikari includes several layers of protection to prevent shop containers and signs from being damaged, accessed, or modified in unintended ways.

📄️等级

QuickShop 提供了一个等级系统，控制玩家可以拥有的商店数量上限。

📄️批量移除商店

如果您有大量商店需要移除，以下方法可以帮您很快完成。

📄️创建与购买

本章节将会指导你如何创建 QuickShop 商店，并与之交互。

📄️商店方块

不只是箱子，其他所有原版容器都可以用来创建 QuickShop 商店！

📄️商店费用

QuickShop 允许服务器管理员配置创建商店和改变价格的费用。

📄️商店历史记录

商店历史记录系统允许玩家与店员在菜单界面中浏览过去的交易记录。

📄️商店清理

商店清理允许管理员自动清理长期不活跃的商店或被封禁玩家的商店。

📄️商店搜索

QuickShop 有一个内置的商店搜索功能，可以在不加载区块的情况下搜索服务器的商店。

📄️Shop States

QuickShop-Hikari 6.3.0.0 introduces Shop States as a separate system from Shop Types.

📄️商店类型

QuickShop-Hikari uses shop types to define the direction of a shop's trade.

📄️告示牌排版

QuickShop-Hikari allows you to customize the contents of shop signs through the RenderComponent system.

📄️告示牌材料

默认情况下，QuickShop-Hikarri 会使用配置文件的材料，但你可以通过命令自行修改。

📄️商店告示牌打蜡

QuickShop 可以为商店告示牌自动打蜡，防止玩家手动编辑其上内容。

📄️堆叠商店

QuickShop 允许你出售或收购指定数量的一捆物品。

📄️推荐价格

这个功能会给玩家推荐物品定价，输入命令 /quickshop suggestprice 即可。

📄️Shop Tags

QuickShop-Hikari 6.3 introduces a player-specific Shop Tag System for organizing and tracking shops.

📄️税收系统

QuickShop 的税收系统可以让服主有更多维护经济平衡的选择。

📄️Text Displays

QuickShop-Hikari 6.3 adds Text Displays, allowing shop information to be shown as floating text above a shop's displayed item.

📄️商店交易菜单

The Shop Trade Menu is QuickShop-Hikari's player-facing GUI for buying from and selling to shops.

📄️WorldEdit & FAWE 支持

QuickShop 内置了 WorldEdit 与 FastAsyncWorldEdit（FAWE）的保护与联动。
