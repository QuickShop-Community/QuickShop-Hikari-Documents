BlueMap 插件

info

找不到在哪里下载 JAR 文件？ 点击这里。

BlueMap 附属允许 QuickShop 在你的 BlueMap 网页地图上显示商店。

玩家可以看到这些信息：

  • 商店所在位置
  • 参与交易的物品
  • 物品的价格
  • 物品的库存
  • 商店的拥有者
  • 商店的交易类型

在 6.2.0.11 后，BlueMap 附属新增了根据商店类型标记不同颜色的功能。

6.2.0.11 新增功能​

BlueMap 附属现已支持：

  • 根据商店类型/状态显示不同的标记点颜色
  • 增强与新商店类型系统的兼容性
  • 增强与新事件系统的同步
  • 更新商店类型时内容刷新更准确

标记点现在会显示如下内容：

  • “出售”类型的商店
  • “购买”类型的商店
  • “冻结”状态的商店

这可以让玩家直接在地图上了解商店的状况。

示例图​

工作原理​

当商店有如下事件时：

  • 创建
  • 移除
  • 更新
  • 冻结或解冻
  • 在“购买”或“出售”类型之间切换

那么，BlueMap 就会更新标记点。

标记点会：

  • 创建时与商店一同出现
  • 删除时与商店一同消失
  • 价格、库存或类型改变时一同更新

无需手动更新。

标记点颜色​

标记点现在可以根据商店状况显示不同的颜色。

标准行为：

  • 出售商店 -> 默认颜色
  • 购买商店 -> 代替颜色
  • 冻结商店 -> 禁用状态的颜色

这样就可以在地图上分辨出不同类型的商店。

新商店类型系统的颜色相关逻辑于 6.2.0.11 版本引入。

配置文件​

config-version: 1

# 是否在打开地图时默认显示标记点组/标记点。
display-by-default: true

# 用作 QuickShop 的图标所在位置。
# 默认以 BlueMap 的 assets 文件夹为相对路径起始点。
icon-file-location: "/assets/chest.png"

# 是否在地图上显示标记点图标。
display-icon: true

# 标记点最大可视范围。
# 适当调低可提升大型服务器环境下的性能。
max-distance: 1000

# 显示在标记点列表中的标签。
# 可用内建变量：
# %item%, %price%, %stock%, %owner%, %type%, %location%
marker-label: "%item%, %price%, %stock%, %owner%, %type%"

# 点击标记点时弹出的文本。
marker-detail: '<span style="font-size: 120%">箱子商店</span><hr><span>拥有者：<strong>%owner%</strong></span><br><span>物品：<strong>%item%</strong></span><br><span>价格：<strong>%price%</strong></span><br><span>库存：<strong>%stock%</strong></span><br><span>类型：<strong>%type%</strong></span><br><span>位置：<strong>%location%</strong></span>'

# 插件每秒刷新商店多少次？
refresh-per-seconds: 5

变量​

有如下内建变量可供使用：

  • %item%
  • %price%
  • %stock%
  • %owner%
  • %type%
  • %location%

这些变量可以显示实时的商店数据，且会自动更新。

性能​

若要优化性能：

  • 在规模较大的服务器上，可考虑降低 refresh-per-seconds 的值。
  • 调低 max-distance 的值，限制渲染范围。
  • 尽量不要让玩家在小片区域内设置大量商店。

这个附属由事件驱动，且只在必要时刷新。

本地化​

BlueMap 附属显示语言跟随 QuickShop 的 game-language 配置。

你也可以在 QuickShop 中的本地化系统中自定义标记点文本：

详见：modules/localization.md

安装​

  1. 安装 BlueMap 插件。
  2. 安装 QuickShop BlueMap 附属。
  3. 重启服务器。

如果没有安装 BlueMap 本体，附属不会生效。

总结​

BlueMap 附属可以：

  • 在网页地图上显示商店
  • 自动更新其中的数据
  • 支持根据商店状况改编商店图标颜色（6.2.0.11 后引入）
  • 兼容新商店类型系统
  • 无需大量配置

推荐需要现代化且依赖网页预览商品的服务器选用。
