经济格式化

QuickShop使用经济格式将平衡格式化为可读文本。

经济插件支持​

默认情况下，QuickShop 会请求经济插件来格式化经济数据，但有些时候可能会失效（例如经济插件代码中返回了 null），那么 QuickShop 将会返回至内部经济格式，确保经济数据可被格式化。

内部格式器​

内部格式器只会在缺少经济插件的情况下使用，但你可以在 config.yml 中选择强制启用它：

  # 这将修复 Vault 或经济插件处理价格时出现的错误，使其返回一个“0”值。
  # 若启用该项，则插件会强制使用“alternate-currency-symbol”中的内容作为经济符号。
  disable-vault-format: false

你可以通过这些选项自定义：

# 是否使用小数格式展示余额。
use-decimal-format: false
# 展示余额的小数格式。
# 默认值为 #,###.##
decimal-format: "#,###.##"
shop:
  # 若 Vault 没有返回经济符号，则 QuickShop 会使用这个符号。
  alternate-currency-symbol: '$'
  # 是否将经济符号显示在数字右侧（如 1234$）。
  # 默认情况下显示在左侧（即 $1234）。
  # 仅当 disable-vault-format 为 true 时有效。
  currency-symbol-on-right: false
  # 小数部分最大位数。
  # 设置为 -1 表示禁用。 （不限位数）
  maxium-digits-in-price: -1
