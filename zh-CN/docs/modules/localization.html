本地化

QuickShop-Hikari 跟随玩家选择的客户端语言。 所有翻译都是由志愿者在 Crowdin 上提供的。

Crowdin 项目​

若要帮助翻译 QuickShop-Hikari，请访问我们的 Crowdin 主页。

Crowdin OTA​

QuickShop-Hikari 会自动通过 Crowdin OTA 更新翻译。 重新加载 QuickShop-Hikari 或重新启动服务器时，对本地翻译文件的任何直接更改都会被覆盖。

这可以让翻译保持最新，无需手动干预。

自定义翻译​

重启或重载后会导致本地改动丢失，因此请勿编辑原文件。 请使用翻译覆盖系统。

从 Github 获取原始文件​

在使用覆盖系统之前，您必须从 Github 获取原始翻译文件（因为本地覆盖文件默认为空）。

点击此处

找到你需要的语言，打开并下载翻译文件。

覆盖 OTA 翻译​

跳转到您的语言对应的 OTA 覆盖文件夹：

MINECRAFT_SERVER_ROOT/plugins/QuickShop-Hikari/override/LOCALE_CODE/messages.yml

你应该会找到一个空白的 YAML 文件。 将其打开。

从原文复制需要修改的键名与键值，放入覆盖文件，然后编辑必要的内容。

你可以完全复制整个文件夹的内容，或者保持文件结构，复制后再将其修改。 未被覆盖设置的翻译键会使用来自 Crowdin OTA 的设置。

翻译支持 MiniMessage 语法。

你可能需要用到 MiniMessage 网页浏览器

使它工作​

保存文件，然后运行 /quickshop reload 命令即可。

更新​

覆盖文件不会自动更新。 上游翻译更新时，你需要手动更改。

调试：我如何找到 Minecraft 使用的本地化语言代码？​

在游戏内输入 /quickshop debug 开启调试模式。 重新加入服务器或改变客户端使用的语言；控制台即会显示使用的语言代码。

强制使用单一语言​

如果您的服务器不面向世界各地的玩家，或者如果您想禁用服务器上的特定语言，则可以在 config.yml 中进行设置。

# 特定玩家语言设置。
# 若玩家使用了禁用的语言，则插件会使用“默认语言”。
#
# 用法：
# - '*' 表示启用所有可用的语言。
#
# 语言可通过 Crowdin OTA 自动更新：
#   https://crowdin.com/project/qs-hikari
#
# 自定义翻译请使用语言覆盖系统：
#   https://quickshop-community.github.io/QuickShop-Hikari-Documents/docs/modules/localization
enabled-languages:
- '*'

例如，要在服务器上仅允许 zh-CN 语言，您可以设置为：

enabled-languages:
  - 'zh-CN'

或者多种语言

enabled-languages:
  - 'zh-CN'
  - 'zh-HK'
  - 'zh-TW'

更改默认游戏语言​

在某些情况下，QuickShop-Hikari需要使用全局默认语言，您可以使用此选项修改默认全局语言。

尽管在绝大多数情况下，QuickShop-Hikari不会使用此选项， 您仍然可以配置它(如果您想要)，我们建议保留默认值。

config.yml 中的注释可能已过时。

# 插件使用的默认语言。
# 设置为“default”表示自动跟随玩家使用的客户端语言。
# 示例语言代码：en_us
game-language: default

禁用 CrowdinOTA​

如果您所在的区域无法访问我们的 OTA 服务器，或者您的连接非常缓慢。 您可以直接禁用 CrowdinOTA，QuickShop-Hikari 仍将使用缓存的翻译或捆绑翻译。

若需禁用 CrowdinOTA，只需在启动标志中加上：

-Dcom.ghostchu.quickshop.localization.text.SimpleTextManager.enableCrowdinOTA=false

🆕 自 6.3.0.0 SNAPSHOT 2 引入​

从 6.3.0.0 SNAPSHOT 2 开始，JVM 启动参数已移动到 config.yml 中`。

使用

use-crowdin-ota: false

自托管 OTA 服务器​

如果你使用 CrowdinCopyDeploy 自行托管翻译服务器，你可以将 OTA 客户端指向自有的服务器。

-Dcom.ghostchu.quickshop.localization.text.SimpleTextManager=<YOUR_SERVER_ADDRESS>

🆕 自 6.3.0.0 SNAPSHOT 2 引入​

从 6.3.0.0 SNAPSHOT 2 开始，JVM 启动参数已移动到 config.yml 中`。

使用

crowdin-host: <YOUR_SERVER_ADDRESS>
