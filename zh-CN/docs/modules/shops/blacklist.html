黑名单系统

服务器管理员可以控制在哪里创建什么类型的商店。

可以根据以下信息限制创建商店：

  • 世界黑名单
  • 世界白名单
  • 物品黑名单
  • 物品描述黑名单

这些规则只影响新创建的商店，不会影响现有商店。

世界限制

QuickShop 现在支持黑名单和白名单模式，方便控制指定世界的商店创建。

世界黑名单​

shop.blacklist-world 中的世界不能创建商店。

shop:
  # 禁用新建商店功能的世界。
  blacklist-world:
    - disabled_world_name

如果某个世界出现在这个列表中：

  • 玩家不能在这里新建商店。
  • 现存的商店仍然可以正常交互。
  • 可以继续与商店交易，除非在别处额外配置。

世界白名单（6.2.x+）​

世界白名单功能让玩家只能在特定世界里新建商店。

shop:
  # 只能在这些世界里新建商店。
  whitelist-world:
    - survival_world
    - skyblock_world

使用 whitelist-world 设置时：

  • 商店只能在这些世界里创建。
  • 其他世界都会自动禁用创建商店功能。
  • 其他世界已存在的商店仍然可以正常交互。

黑名单与白名单​

适用黑名单的情况：

  • 你想要商店不能在指定的世界出现。

适用白名单的情况：

  • 你只想要商店出现在某个世界里。
  • 你的服务器有多个世界（创造、活动、小游戏等）。
  • 你想要更加严格地管控经济。

推荐大型多世界服务器使用白名单模式。

物品限制

你也可以限制哪些物品能上架。

物品名称黑名单​

在 config.yml 中，将物品添加进 blacklist 中：

# 不能在商店中出售的物品。
# 拥有 quickshop.bypass.<itemID> 权限的玩家无视此限制。
# 若要引用物品查找表，请在名称前加上 @ 符号。
# 引用物品的绕过权限为 quickshop.bypass.reference。
blacklist:
  - Bedrock

blacklist 支持：

  • Bukkit 材料名
  • 物品引用 标签（以 @ 开头）
  • 通配符模式（6.2.0.11+）

示例通配符：

blacklist:
  - "*_SPAWN_EGG"
  - "*_AXE"

物品描述黑名单​

通过关键词限制特定描述的物品上架：

shop:
  # 包含指定关键词描述的物品禁止上架。
  # 不会影响已存在的商店。
  blacklist-lores:
    - "灵魂绑定"

如果物品包含符合条件的描述：

  • 阻止创建商店。
  • 现有的商店不受影响。

旧商店

黑名单与白名单规则只会对如下过程生效：

  • 新建商店

它们不会：

  • 删除已有商店
  • 禁用已有商店

若你需要删除现有商店，请试着：

  • /qs clean
  • /qs cleanghost
  • 手动移除

推荐配置

对于多世界服务器：

shop:
  whitelist-world:
    - survival
    - skyblock

对于创造服限制：

shop:
  blacklist-world:
    - creative
    - minigames

总结

黑名单系统可以：

  • 控制哪些世界允许创建商店
  • 限制特定的物品上架
  • 通过描述禁用自定义物品上架
  • 使用通配符模式
  • 保护特殊用途世界

世界白名单支持（6.2.0.11+）允许更严格安全地控制大型服务器。
