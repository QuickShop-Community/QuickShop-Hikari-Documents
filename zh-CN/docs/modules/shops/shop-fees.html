商店费用

QuickShop 允许服务器管理员配置创建商店和改变价格的费用。

配置​

shop:
  # 创建商店的费用。设置为 0 表示免费。
  cost: 10
  # 是否在玩家的商店被破坏/删除时返还费用？
  refund: false
  # 是否从税收账户退款？
  # 尽可能满足退款要求；如果账户余额不足，玩家可能不会收到所有退还款项。
  refund-from-tax-account: false
  # 修改商店价格是否收费？
  # 有助于缓解频繁改价带来的价格战。
  price-change-requires-fee: true
  # 修改商店价格的费用。
  fee-for-price-change: 50
  # 修改商店名称的费用。
  name-fee: 0
  # 商店名称的最大长度。
  name-max-length: 32
  # 商店维护费用。
  # 若店主无力支付，则商店即日移除。
  ongoing-fee:
    enable: false
    # 维护费允许最长拖欠多久？
    ticks: 42000
    # 每个商店收取多少维护费？
    cost-per-shop: 2
    # 是否不对无限商店计费？
    ignore-unlimited: true

创建费用​

它由 shop.cost 控制，设置为 0 表示免费。
shop.refund 启用后即可在商店删除或被破坏时退还创建费用。 若需要从 QuickShop 收税账户退款，那么还需要启用 shop.refund-from-tax-account。 如果税务帐户没有足够的钱，玩家可能无法收到退款。

修改价格费用​

防止玩家频繁改变商店价格，只需开启 shop.price-change-requires-fee 即可。
启用后，玩家每次更改价格都会被收取 shop.fee-for-price-change 对应的金额。

命名费用​

将 shop.name-fee 设置为非零值，可让玩家付费修改商店名称。
玩家只有支付费用后才可修改商店名称。

维护费用​

防止玩家通过大量商店破坏市场平衡，你可以启用这个功能。

启用后，玩家每 shop.ongoing-fee.ticks 刻就需要为每个商店支付 shop.ongoing-fee.cost-per-shop 设置的维护费。

如果玩家无力支付费用，那么商店就会被删除。

收税​

QuickShop 有一个可配置的税收系统。

配置​

# 税收百分比（小数）
# 例如：玩家甲从乙处购买了价值 50$ 的物品，那么甲支付 50$，而乙赚了 (1-0.05)*50$，税收账户收取 0.05*50$。
tax: 0.05

# 税款流向的虚拟账户。
# 将其设置为 "" 可禁用（税收功能仍然有效，但会直接销毁）
tax-account: tax

# 是否禁用无限商店的税收
tax-free-for-unlimited-shop: false

# 是否在交易后显示收取的税
show-tax: false

交易税​

每次交易都会拿出一小部分充当税收，由 tax` 选项控制。

1 表示 100%，而 0.05 则表示 5%，你需要自行将小数与百分比进行转化。

你也可以启用 show-tax 选项，使得玩家可以在交易时看到收取的税。

税收账号​

默认情况下，所有税款都会流入名为 tax 的账户。
根据你的服务器经济插件及玩法设计差异，默认设置可能不完全适合你，需要修改它。

tax-account 可填入玩家名称或 uuid。
