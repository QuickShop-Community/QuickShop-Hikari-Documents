6.2.0.9

主要改动​

修复了包括界面在内的刷物品漏洞​

该构建版本修复了菜单界面内最近出现的刷物品漏洞。

大量事件改动​

由此见 Discord 事件系统相关更新日志

控制面板组件系统大改​

商店控制面板被大改为按不同部分分类。 这允许第三方插件能更简单地向其中添加额外组件。 同样添加了 ControlComponentGenerateEvent 事件，会在 ControlComponent 生成的 PRE、MAIN 及 POST 阶段调用。 MAIN 阶段支持替换 ControlComponent 对象，可在发送控制面板期间更改其内容。

引入了增强发包系统​

  1. 关于：

    • 模块化且灵活的 Minecraft 虚拟物品发包管理工具。
    • 支持 ProtocolLib 与 PacketEvents 插件。

  2. 自定义包工厂：

    • 1.20.x 与 1.21.x PacketFactory 的模块化实现。
    • 包类型：
      • 生成包：在指定位置生成虚拟物品实体。
      • 元数据包：更新虚拟物品的可视化数据。
      • 速度包：向实体添加动量/速度（当前可选）。
      • 销毁包：在客户端视角下移除实体。

  3. 错误处理与记录：

    • 增强了调试日志，使其可追踪发包相关问题。
    • 缺失工厂类或未注册监听器的详细错误消息。

改进：​

  • 更好的模块化设计，实现对未来版本 Minecraft 的支持。

弃用：​

  • 旧的发包处理机制将会被新的发包系统替代。

事件系统大改​

新增内容​

  • event/Phase.java - 引入基于阶段的事件系统，用于检查事件过程的不同阶段。
  • event/PhasedEvent.java - 设置不同阶段的事件，允许更优的事件状态管理。

发包处理事件：​

  • event/packet/handler/PacketHandlerAddedEvent.java - 在系统内注册新发包处理器时调用。
  • event/packet/handler/PacketHandlerInitEvent.java - 在发包处理器初始化时调用，可用于调试或自定义安装。
  • event/packet/send/PacketHandlerSendDestroyEvent.java - 数据包指导客户端视角的实体销毁时触发。
  • event/packet/send/PacketHandlerSendMetaEvent.java - 实体元数据通过发包发送时触发。
  • event/packet/send/PacketHandlerSendSpawnEvent.java - 在实体通过发包交流生成时触发。

商店事件​

  • ShopUpdateEvent 被替换为 ShopDatabaseEvent
  • ShopAuthorizeEvent 被替换为 ShopPermissionCheckEvent
  • ShopClick、ShopCreate、ShopDelete、ShopLoad 被分别替换为名称相似的事件，现位于 event.management 包，且为阶段事件。

商店设置事件：​

  • event/settings/ShopSettingEvent.java - 处理商店设置动态修改的事件。
  • event/settings/package-info.java - 包含元数据的商店设置文档包。
商店类型相关设置：​
  • event/settings/type/ShopCurrencyEvent.java - 处理商店内使用的货币类型更改。
  • event/settings/type/ShopDisplayEvent.java - 在商店的展示设置（如悬浮字、告示牌等）更改时触发。
  • event/settings/type/ShopItemEvent.java - 在商店内出售的物品更新时触发。
  • event/settings/type/ShopNameEvent.java - 在商店名称更新时触发。
  • event/settings/type/ShopOwnerEvent.java - 负责管理商店转让与更改相关内容。
  • event/settings/type/ShopOwnerNameEvent.java - 拥有者名称发生变化时触发。
  • event/settings/type/ShopPlayerGroupEvent.java - 处理玩家组与商店相关的更新。
  • event/settings/type/ShopPriceEvent.java - 商店内物品价格变化时触发。
  • event/settings/type/ShopSignLinesEvent.java - 负责管理商店告示牌显示内容相关更新。
  • event/settings/type/ShopTaxAccountEvent.java - 在商店税收账户更新时触发。
  • event/settings/type/ShopTypeEvent.java - 负责记录商店分类或类型的改动。
  • event/settings/type/ShopUnlimitedEvent.java - 负责处理商店无限库存状态相关设置。
商店优惠系统：​
  • event/settings/type/benefit/ShopBenefitAddEvent.java - 在商店增加新优惠（折扣或老用户回馈等）时触发。
  • event/settings/type/benefit/ShopBenefitEvent.java - 负责处理商店优惠变动相关事件。
  • event/settings/type/benefit/ShopBenefitRemoveEvent.java - 在商店优惠被移除时触发。

移除内容​

  • event/details/ShopItemChangeEvent.java - 替换为 ShopItemEvent.java 以保证更连贯的结构。
  • event/details/ShopNamingEvent.java - 并入 ShopNameEvent.java。
  • event/details/ShopOwnerNameGettingEvent.java - 替换为 ShopOwnerNameEvent.java。
  • event/details/ShopOwnershipTransferEvent.java - 现交由 ShopOwnerEvent.java 处理。
  • event/details/ShopPlayerGroupSetEvent.java - 并入 ShopPlayerGroupEvent.java。
  • event/details/ShopPriceChangeEvent.java - 并入 ShopPriceEvent.java。
  • event/details/ShopTypeChangeEvent.java - 替换为 ShopTypeEvent.java。
  • event/details/ShopUnlimitedStatusEvent.java - 现通过 ShopUnlimitedEvent.java 管理。
  • event/display/ShopDisplayItemDespawnEvent.java - 因 ShopDisplayEvent.java 移除。
  • event/display/ShopDisplayItemSafeGuardEvent.java - 并入更宽泛的显示事件分类。
  • event/economy/ShopTaxAccountChangeEvent.java - 现囊括于 ShopTaxAccountEvent.java。
  • event/economy/ShopTaxAccountGettingEvent.java - 因重构商店经济系统而被弃用。
  • event/packet/PacketHandlerAddedEvent.java - 移动至 event/packet/handler/PacketHandlerAddedEvent.java。
  • event/packet/PacketHandlerInitEvent.java - 交由 event/packet/handler/PacketHandlerInitEvent.java 处理。

修改​

  • event/AbstractQSEvent.java - 基于事件结构更新，以支持阶段事件执行。
  • event/QSCancellable.java - 添加了新的取消条件，防止非预期的事件结束。

包事件：​

  • event/package-info.java - 更新以反映新的事件结构。
  • event/packet/PacketHandlerEvent.java - Now supports additional packet handling scenarios.

Minor Changes​

  • If a player doesn't have permissions for CONTROL_PANEL_UI it'll open the TRADE_UI for them
  • Added the quickshopdontsend override to allow server owners to prevent certain messages from sending(paper only)
  • Made it so invalid chat entries for UIs escape the chat ui

Config Changes​

  • added shop.control-panel to control what components of the text control panel are enabled.
  • added shop.sign-wax to control if the shop sign is waxed or not, default is false.
  • added shop.display-protocol which allows you to select packetevents or protocollib for packet handling

Fixes​

  • readded the /qs history permissions to the default quickshop.player
  • fixed issue where some folks wouldn't have the encoded db column
  • Fixed issue with reached-maximum-can-create not being implemented correctly
  • fixed issue where pistons would move shulker shops.
  • fixed issue where colored shulkers could be bought and put inside non-colored shulker
  • fixed issue with griefprevent /transfer command not unregistering owner
  • fixed issue where signs weren't updated when lock was set to false
  • Fixed issue where slime compat explosive pick wasn't being caught by QS(Thanks to YuanYuanOwO and Starfruit)
  • Fixed exploit(thanks to macaw/casper for being the first to report this)

Version Changes​

  • Removed support for 1.18 and 1.19. These versions had minimal usage.
  • Added support for 1.21.5
