6.2.0.8

主要改动​

  • 初步实现 Folia 支持
  • 增加了 CONTROL_PANEL_UI 选项，允许你通过菜单而非聊天栏界面进行管理。
    • 在这个菜单中你可以添加店员，转让商店，设置出售模式，修改价格以及删除商店！
  • 重新加入了 QS 历史界面
  • 移除了真实物品与实体展示功能；相较虚拟展示并无优势且总出现问题。
    • 若没有安装 ProtocolLib 或版本过低，则默认不展示物品。
  • 添加了 /qs browse [世界名称] 命令，允许玩家浏览全服或指定世界的商店。
  • 添加了 TRADE_UI，玩家可通过该界面从商店购买或出售一定数量的物品。
  • 更新对 MC 1.21.3 与 1.21.4 的支持。
  • 现已兼容 VaultUnlocked。

Minor Changes​

  • 新增即将出现的 2 种新交互行为。 CONTROL_PANEL_UI 与 TRADE_UI
  • 将税费设置为 0 时将不再出现相关消息。
  • 添加了 /qs staffall 用于查询商店的所有店员。
  • 添加了新的商店模式：冻结。
    • 允许管理员/商店店员临时阻止商店相关交易。
    • 该模式可在商店管理菜单中浏览。
    • 该模式亦被加入聊天栏设置菜单中。
    • 该模式增加了两条新命令：/qs silentfreeze 与 /qs freeze
  • 现在，若没有看向商店，则 /qs suggestprice 的默认对象调整为手中的物品。
  • 添加了 shop.finding.global 权限，用于忽略 /qs find 命令的距离限制。
  • 现在组成商店的告示牌会被默认打蜡以防止其他玩家的更改（感谢 ThiagoROX 的贡献）
  • 添加了 SignOpen 监听器（感谢 ThiagoROX 的贡献）
  • 添加了子命令覆盖（感谢 ThiagoROX 的贡献）

内部改动​

  • 添加了样式指导教程。
  • 尽可能增加了最终内部代码。
  • 现在取消设置商店名称也会调用 ShopNamingEvent 了。
  • 添加了 ShopUnlimitedStatusEvent 事件，会在商店切换无限库存时触发。
  • 将事件重排为了不同的包。 会导致依赖于事件的插件无法正常工作。

杂项改动​

  • 添加了 Github 赞助者。

兼容插件改动​

  • Towny
    • 添加了“城镇废墟”功能，使得城镇变为废墟时删除其内的所有商店。

附属插件改动​

SuperiorSkyblock​

  • 被踢出的玩家会一并删除其设置在岛屿上的商店。

Fixes​

  • 修复了 Velocity 与 Bungee 兼容 jar 的相关问题
  • 修复了 Towny 兼容 jar 不会在清理地皮或删除城镇时清除商店的问题。
  • 修复了潜影盒绕过物品限制的问题（感谢 TauCubed 的贡献）
  • 修复了城镇/国家账号在带有 Essentials 插件下的查询问题（感谢 galacticwarrior9 的贡献）

备注​

  • 未来版本可能会去除对 1.18/1.19 的支持。
