  • 文档更新
  • 配置注释更新
  • 告示牌解析器实现？

6.2.0.11

主要改动​

  • 移除了 Spigot 平台模块，检测到核心类型为 Spigot 时自动禁用 QS。 即，除非展示物品使用的协议发生变化，否则 QS 不会为每个版本更新。
  • 完全翻新经济相关代码
    • 经济相关系统拥有了新类
    • 经济与收益相关的事件不兼容先前版本。
  • 新增不同类型告示牌内容自定义，允许自由配置，空字符串（''）表示留空一行。
  # 商店的告示牌样式。
  layout:

    # “购买”类型商店的告示牌样式。
    BUYING:
      line1: "header"
      line2: "trading"
      line3: "item"
      line4: "price"

    # “冻结”状态商店的告示牌样式。
    FROZEN:
      line1: "header"
      line2: "trading"
      line3: "item"
      line4: "price"

    # “出售”类型商店的告示牌样式。
    SELLING:
      line1: "header"
      line2: "trading"
      line3: "item"
      line4: "price"
  • 物品黑名单列表新增通配符支持（感谢 bennycallanan 的贡献）

    • 物品黑名单配置新增通配符支持，允许玩家以更精简的配置过滤一类物品。

    • 功能介绍

      • 诸如 *_AXE 和 *_SPAWN_EGG 的通配符现在可以在黑名单配置中生效
        • 表示任何字符，? 表示任意单个字符
      • 匹配规则大小写敏感
  • 重写菜单系统（感谢 Yusakidev 的贡献）
    • 新增自定义菜单的 gui.yml 配置。
    • qs browse 命令界面过滤优化
    • 优化菜单系统，使其更稳定且更少报错。
    • 新增 gui.yml，可完全配置菜单界面排版与显示文本
    • 浏览菜单包含：搜索、排序（按价格、名称或库存）及筛选（全部、购买、出售、库存量）功能
    • 员工菜单：搜索玩家/员工选择
    • 优化了商店浏览的物品分组页面
    • 重写所有菜单页面，使其可自由配置显示内容与描述
  • 新增 QS 与 worldedit 内部兼容。
  • 优化了税收功能，使其更加灵活，更易配置。
    • 新增渐进式税收系统，允许根据玩家存款量收取税费。（由 YuanYuanOwO 提出）
    • 新增对交互商店、商店拥有者或双方进行收税的功能
    • 所有税收相关配置都位于配置文本的 shop-tax 部分。 可能需要重新配置税收相关功能。
    • 新增 ShopEnhancedTaxEvent 事件，将旧的 ShopTaxEvent 标为弃用。
    • 新增 TaxManager 及 TaxProvider 接口，允许附属/第三方开发者引入自定义税收功能。

附属/兼容更新​

  • 新增 UltimateClaims 兼容
  • 新增 SimpleClaimSystem 兼容
  • 新增（作者为 Pika 的）Quests 插件附属
  • 新增 BetonQuest 附属
  • 新增 Pl3xMap 附属
  • MatcherPlus 兼容更新
    • 新增 CrazyCrates 支持
    • 新增 ExcellentCrates 支持
    • 新增 SilkSpawners 支持。
  • WorldGuard 兼容更新（感谢 golovin12 的贡献）
    • 新增清除权限处理：
      • 区域拥有者与成员自动拥有在区域内创建商店并与商店交互的权限。
      • 其他玩家必须通过 WorldGuard 的标志设置（quickshophikari-create、quickshophikari-trade）才可创建商店或与商店交易。
    • 若商店位于区域外，则使用默认的 QuickShop 行为检查（无额外限制）
  • 对 bluemap 新增基于商店状态的颜色标记点（感谢 YusakiDev 的贡献）
  • 更新 dynmap/towny 附属，使其使用 ShopTypeEnhancedEvent 而非原先的 ShopTypeEvent。
  • 移除 worldedit 兼容，现已合并至插件主体。
  • 新增 worldguard 兼容的全局标志支持。

内部/开发者 API​

  • 移除了部分标为弃用的方法与类。
  • 更新了交互管理。 增强其灵活程度，并允许额外添加
    • 涉及 InteractionBehavior 与 InteractionType 类。
    • InteractionType 类表明交互类型，如：STANDING_LEFT_CLICK_SIGN、STANDING_LEFT_CLICK_SHOP
    • InteractionBehavior 则进一步解释 InteractionType 的行为，如 CONTROL_PANEL 和 TRADE_UI
  • 新增 UserLimitCalculationEvent，允许对玩家使用自定义限制。
    • 适用于限制玩家拥有的商店数量，或通过等级系统在不需要额外实现 RankLimiter 的情况下为不同等级的玩家设置不同的商店数量上限。
  • 新增 ShopLayoutProvider 接口，及其默认实现。
    • 允许商店使用自定义排版，进一步自定义界面。
    • 允许开发者覆写默认的排版样式，编写自己的实现。
  • 如何自行制作？
    • 首先，实现你需要注册 InteractionManager 的类：
    •    InteractionManager manager = QuickShop.getInstance().getInteractionManager();

         manager.interaction(new MyTradeInteraction());
         manager.behavior(new MyTradeBehavior());
  • 将部分 Apache Commons 调用改为可简单替代的内置 java 方法，节省了约 1100 毫秒/次方法的调用
  • 弃用了 ShopType 常量，以及 ShopTypeEvent 事件。 改为新的 IShopType 接口与实现类。
    • 新事件为 ShopTypeEnhancedEvent。
    • 允许第三方附属新增商店类型， 简化翻译代码检查。
  • 更新配置系统，采用增强的 yaml 格式
    • 允许配置文件自动更新而无需编写复杂脚本
    • 允许配置系统不依赖 minecraft 本身。
  • 将逻辑上的 PaperLib 替换为了原生 PaperAPI 调用。

次要改动​

  • 将 Java 版本提升至 21
  • 新增 shop.display-allow-enchants 设置，允许启用或禁用商店内物品显示附魔。
  • 尝试解决了 packetevents 的虚拟展示物品 itemstacks 不支持自定义附魔的问题。
  • 对模式切换图标的 shop-type 使用了本地化翻译的字符串（感谢 ExyiN 的贡献）
  • 将兼容的 Residence 版本进行了提升（感谢 YuanYuanOwO 的贡献）
  • 新增世界白名单支持（感谢 wling-art 的贡献）
  • 新增 /qs databse save 命令，可将所有带脏标记的商店保存至数据库。
  • 将 _SHOPBLOCK 交互细分为 _SHOPBLOCK 与 _CONTAINER。
    • _SHOPBLOCK 表示与商店相关，而 _CONTAINER 表示与非商店的有效容器相关。
  • 命令界面现在可以选择使用物品栏呈现，需要增加打开商店界面的二级选项时很有用。
  • 将 crowdin 参数从系统属性移动到了 config.yml
    • crowdin-host
    • use-crowdin-ota
