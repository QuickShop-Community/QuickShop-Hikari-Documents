隐私政策

使用 QuickShop-Hikari 提供的服务时，我们将会向服务提供方发送部分必要或可选的信息。

bStats​

我们使用 bStats.org 来收集统计指标，以便更好地改进我们的产品。

bStats的隐私政策

收集到的所有数据将显示在此页面上： bStats - QuickShop-Hikari

禁用 bStats 统计数据​

只需更新 QuickShop-Hikari 的隐私策略配置，即可将其禁用：

# 隐私设置可控制有关数据的发送与否，也是我们对隐私公开性的尝试。
# 所有隐私审查行为均可通过命令 `/quickshop paste` 生成的内容浏览。
# 若要完全阻止 bStats 收集使用情况数据，请前往 /plugins/bStats/config.yml 修改设置。
privacy:
  # 分类控制
  type:
    # 包含 bStats 中以 `Statistic -` 开头的统计数据。所有收集的数据可在 https://bstats.org/plugin/bukkit/QuickShop-Hikari/14281 页面浏览。
    STATISTIC: true
    # 包含 bStats 中以 `Research -` 开头的统计数据。所有收集的数据可在 https://bstats.org/plugin/bukkit/QuickShop-Hikari/14281 页面浏览。
    RESEARCH: true

注：先前收集的数据不会从 bStats 删除。 若有需求，请联系 bStats 管理员。
注意：QuickShop 遵循全局 bStats 设置。 若 bStats 全局禁用，那么 QuickShop 不会向 bStats 发送数据。

RollBar错误跟踪​

我们通过 Rollbar 收集错误报告。 与 QuickShop-Hikari 相关的错误可能会自动提交给我们的 Rollbar 项目。

您可以在这里查看 Rollbar 的隐私政策。

包括:

  • 时间
  • 错误和堆栈跟踪
  • 操作系统
  • 操作系统架构
  • 操作系统版本
  • 系统 CPU 核心
  • Java版本
  • 服务器/Bukkit 构建版本
  • 玩家数量
  • 在线模式
  • 您的 QuickShop-Hikari 个人ID

重新生成 QuickShop-Hikari 个人 ID​

首次安装 QuickShop-Hikari 时，插件会生成一个独特的 ID，并将其写入config.yml。
ID 完全随机，不受其他信息影响。 它会用于 bug 追踪及其他需要分辨不同 QuickShop-Hikari 实例的情况。

如果没有插件正在使用此ID，您可以从配置文件中删除它，以便QuickShop-Hikari能够生成一个新的个人ID。

禁用 Rollbar 错误跟踪​

若需要禁用 Rollbar 错误追踪，只需更改 QuickShop-Hikari 的配置：

# QS 是否允许自动向作者报告错误？
# 这会在服务器启动时自动创建数据恢复或调试用的剪贴板。
auto-report-errors: true

注：先前收集的数据不会从 Rollbar 删除。 可联系 QuickShop-Hikari 的开发者请求将其删除。

剪贴板​

通过 /quickshop paste 创建剪贴板内容后，你的数据将会被上传至 Lucko 的 bytebin 剪贴板。
若要防止数据上传，你可以通过命令 /quickshop paste file 保存至硬盘，这些内容将会留在本地而不会上传至网络。

剪贴板浏览器托管在 Github Pages 上，通过 Cloudflare Worker 访问上传的数据。

敏感数据会在生成剪贴板内容时进行屏蔽处理。 请勿将剪贴板内容发送给陌生人。

更新相关​

QuickShop-Hikari 会向 CodeMC.io 的 Nexus 服务发送更新检查请求。

如果需要关闭更新检查，只需按如下示例更改配置即可：

# 是否允许 QS 检查更新？
updater: false
