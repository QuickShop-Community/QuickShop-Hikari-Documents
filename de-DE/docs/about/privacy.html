Privatsphäre

When using the QuickShop-Hikari service, we will send the necessary and partial optional data to the relevant service provider.

bStats​

Wir verwenden bStats.org um statistische Angaben zu sammeln, damit wir unsere Produkte verbessern können.

bStats' Datenschutzrichtlinien

Alle gesammelten Daten werden auf dieser Seite angezeigt: bStats - QuickShop-Hikari

bStats Statistiken deaktivieren​

Um das senden von Statistiken an bStats zu verhindern kannst du den bStats Service in der QuickShop-Hikari Konfiguration deaktivieren:

#Privacy Controller allows you turn on/off some options that related to privacy. This is our move towards privacy transparency.
#By audit all privacy reviewing activities, execute `/quickshop paste` to generate a paste and check `Privacy Logs` section.
#To out-put from bStats completely, go to /plugins/bStats/config.yml.
privacy:
  # Category Control
  type:
    # Including bStats metrics with `Statistic - ` prefix, see all metrics we collected on https://bstats.org/plugin/bukkit/QuickShop-Hikari/14281
    STATISTIC: true
    # Including bStats metrics with `Research - ` prefix, see all metrics we collected on https://bstats.org/plugin/bukkit/QuickShop-Hikari/14281
    RESEARCH: true

Hinweis: Bereits gesammelte Daten werden nicht von bStats entfenrnt. Um existierende Daten zu entfernen, kontaktiere bitte die bStats Administratoren.
Hinweis: Wir respektieren deine globalen bStats Einstellungen. Solltest du bStats in den globalen einstellungen deaktiviert haben, werden wir keine Daten an bStats senden.

Rollbar Fehlerverfolgung​

Wir verwenden Rollbar um Fehlermeldungen zu sammeln. All errors on your server which related to QuickShop-Hikari will be automatically submit to our Rollbar bin.

Du kannst Rollbar's Datenschutzrichtlinien hier einsehen.

Beinhaltet:

  • Zeit
  • Fehler und StackTrace
  • Name des Betriebssystem
  • Typ des Betriebssystems
  • Version des Betriebssystems
  • System-CPU-Kerne
  • Java Version
  • Server/Bukkit Build Version
  • Spieler auf dem Server
  • Online-Modus
  • Deine einzigartige QuickShop-Hikari-ID

Regenerate QuickShop-Hikari unique ID​

While you install QuickShop-Hikari in fresh, the your unique ID will be generated and write into your config.yml.
The ID does not depend on any other information for calculation and is completely random, It is used in our bug tracking and other scenarios where different QuickShop-Hikari instances need to be identified.

In case you are sure that no addon is using this value, you can remove this from the configuration file so that QuickShop-Hikari will generate a new unique ID.

Rollbar Fehlerverfolgung deaktivieren​

Um die Rollbar Fehlerverfolgung zu verbieten kannst du den Rollbar Dienst in der QuickShop-Hikari Konfiguration deaktivieren:

# Soll es QS erlaubt sein, Fehler automatisch an den Autor weiter zu leiten?
# Es wird ausserdem eine Paste zur Datenwiederherstellung oder zum Debuggen erstellen, wenn der Server startet.
auto-report-errors: true

Hinweis: Bereits gesammelte Daten werden nicht auf Rollbar gelöscht. Um vorhandene Daten zu entfernen, wende dich an den QuickShop-Hikari Entwickler.

Paste​

When you creating a paste by /quickshop paste command, you data will upload to Lucko's Bytebin.
To avoid data uploading, you can create local paste by using command /quickshop paste file, the paste will save to your local disk without uploading.

Der Paste Viewer wird auf GitHub Pages gehostet und greift auf die hochgeladenen Daten über Cloudflare Workers zu.

Während wir deinen Paste generieren, zensieren wir sensible Daten. Sende deinen Paste trotzdem nur an Personen, denen du vertraust.

Aktualisierer​

Um nach Updates zu schauen wird QuickShop-Hikari den Nexus von CodeMC.io nach Updates fragen.

Um das überprüfen nach Updates zu deaktivieren, kannst du es in der Konfiguration anpassen:

#Soll QS nach Updates suchen dürfen?
updated: false
