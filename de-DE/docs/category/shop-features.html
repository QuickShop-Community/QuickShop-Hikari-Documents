Shop Features

All features related to a quickshop.

📄️ Admin Shop (Unlimited Shop)

QuickShop provides a feature that allow you set a shop to unlimited space (for buying shop) or unlimited stock (for selling shop).

📄️ Shop Benefits

The Shop Benefits feature allows you to split a shop's revenue among multiple players.

📄️ Blacklist System

Server administrators can control where and what shops can be created.

📄️ Shop Staff (Inside Control Panel)

Shop Staff Management

📄️ Shop Control Panel (GUI)

The Shop Control Panel allows players to manage their shop using a GUI interface instead of chat prompts.

📄️ Shop Control Panel

The Shop Control Panel allows players to manage their shops quickly and safely.

📄️ Display Item

QuickShop provides a display feature that helps players identify the item sold or purchased by a shop.

📄️ Per shop permission management

QuickShop-Hikari provides a system for controlling each shop's permissions individually.

📄️ Price Limiter

QuickShop provides a price limiter that lets you set minimum and maximum item prices on your server.

📄️ Protection Checker

QuickShop uses a utility called Protection Checker to prevent players from creating shops where they do not have build access (for example, at spawn).

📄️ Shop Protection

Player Protection

📄️ Ranks

QuickShop provides a ranks system to allow control the maximum shops that player can own.

📄️ Batch remove shops

If you have a massive amounts of the shop need to remove, there are some ways you can do that quickly.

📄️ Create and purchase

This page of document will help you learn how to create and purchase a quickshop.

📄️ Shop Blocks

Not only Chests, but also all Containers all supported used for QuickShop containers!

📄️ Shop Fees

QuickShop allows server administrators to configure fees for creating shops and changing prices.

📄️ Shop History

The Shop History system allows players and staff to review past transactions in a visual GUI.

📄️ Shop Purger

Shop Purger allow server administrator purge the shops if the player in idle or banned.

📄️ Shop Search

QuickShop has a built-in shop search feature that lets you search the server's shops without loading chunks.

📄️ Shop Types

QuickShop supports multiple shop types, allowing shops to behave differently depending on their mode.

📄️ Sign Layout

QuickShop allows you to fully customize how shop signs are structured.

📄️ Sign Material

By default, QuickShop-Hikari uses the default brand material from the configuration file, but you can modify it to other brands for your store with the command.

📄️ Shop Sign Waxing

QuickShop can automatically wax shop signs to prevent players from editing them manually.

📄️ Stacking Shop

QuickShop allows you to sell or buy multiple items in bundles.

📄️ Suggest Price

This feature provides your players with price suggestions for items of interest on your server by command /quickshop suggestprice.

📄️ Taxation System

QuickShop includes a taxation system designed to give server owners more flexibility and control over shop-based income.

📄️ Shop Trade Menu

The Shop Trade Menu is the player-facing trading interface.

📄️ WorldEdit & FAWE Support

QuickShop includes built-in protection and integration for WorldEdit and FastAsyncWorldEdit (FAWE).
