# Localization

QuickShop-Hikari allows player-facing messages and GUI text to be customized through its localization system.

## Localization Library

Looking for a particular localization key?

[Open the Localization Library](/localization)

The library provides searchable information about localization keys, default messages, placeholders, GUI usage, and source-code references.
