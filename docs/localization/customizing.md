# Customizing Messages

QuickShop-Hikari localization messages can be customized through the plugin's language resources.

Use the [Localization Library](/localization) to find a key, inspect its default value, and see where the generator detected that key being used.

When editing messages, preserve placeholders required by the message unless you intentionally understand the effect of removing them.
