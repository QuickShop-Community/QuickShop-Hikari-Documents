# Localization Placeholders

Some localization messages contain numbered placeholders such as:

```text
{0}
{1}
{2}
```

The value substituted for each placeholder depends on the localization key and the code that sends the message.

The [Localization Library](/localization) displays placeholders detected by the generator. When metadata documents a placeholder, the library also displays its human-readable meaning.
