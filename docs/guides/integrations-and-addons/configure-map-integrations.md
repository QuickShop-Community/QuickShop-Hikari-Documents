# Configure Map Integrations

**Goal:** Show shop information on a compatible web map.

**Before you begin:** An installed web map and a compatible QuickShop addon.

> **Version note:** Features and configuration keys can differ by QuickShop-Hikari release. Verify the linked reference against the version installed on your server.

## Walkthrough

### 1. Select a supported map

Review BlueMap, Dynmap, squaremap, or other official addon documentation.

### 2. Install matching versions

Check addon and map compatibility before enabling.

### 3. Configure display scope

Choose which worlds, shops, or markers should be exposed according to documented options.

### 4. Refresh map data

Follow the addon instructions to populate or update markers.

### 5. Test permissions and privacy

Check the public map as a normal visitor and avoid exposing private shop data.

## Verify the result

Markers or overlays appear as documented and link to the correct locations.

## If something goes wrong

- Check the server console for QuickShop-Hikari and dependency errors.
- Repeat the workflow on a staging server with a non-operator test account.
- Compare your configuration and permissions with the linked reference.
