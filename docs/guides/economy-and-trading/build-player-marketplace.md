# Build a Player Marketplace

**Goal:** Create a usable marketplace with independent player shops.

**Before you begin:** A working economy, player shop permissions, and a protected build area.

> **Version note:** Features and configuration keys can differ by QuickShop-Hikari release. Verify the linked reference against the version installed on your server.

## Walkthrough

### 1. Plan the layout

Reserve space for stalls, paths, signage, and accessible shop containers.

### 2. Choose protection rules

Use a compatible protection plugin and confirm that players can interact with shop containers as intended.

### 3. Establish shop policies

Decide whether to impose shop limits, taxes, or restricted items.

### 4. Run a pilot

Invite a few players to create selling and buying shops and test purchases.

### 5. Publish a short guide

Explain how to create, restock, price, and remove shops, and link players to your rules.

## Verify the result

Different players can operate shops without unintentionally editing or breaking one another’s shops.

## If something goes wrong

- Check the server console for QuickShop-Hikari and dependency errors.
- Repeat the workflow on a staging server with a non-operator test account.
- Compare your configuration and permissions with the linked reference.
