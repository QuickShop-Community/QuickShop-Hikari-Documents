# OpenInv

:::info

Can't find where to download the JAR? [Click here](../faq/where-addons-compacts-at).

:::

This compatibility module allows players to use their Ender Chest as a shop container and share its contents.

## Usage

1. Create a regular shop
2. Looking at that shop, execute command `/quickshop echest`
3. You're done!
