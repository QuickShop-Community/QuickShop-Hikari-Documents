# SuperiorSkyBlock

:::info

Can't find where to download the JAR? [Click here](../faq/where-addons-compacts-at).

:::

This module added [SuperiorSkyBlock](https://www.spigotmc.org/resources/87411/) supports.

## How does it work?

Island owners receive full control of all shops on their islands. Those shops are automatically deleted when their owners leave the island team.

## Configuration

```yaml
owner-create-only: false
delete-shop-on-member-leave: false
```
