# WorldEdit

:::info

Can't find where to download the JAR? [Click here](../faq/where-addons-compacts-at).

:::

As of 6.2.0.11, this is no longer a separate compatibility module — it is now built directly into QuickShop. Find out more [here](../../shop-management/worldedit.md).

This module deletes shops in a WorldEdit region to prevent ghost shops from being created.
