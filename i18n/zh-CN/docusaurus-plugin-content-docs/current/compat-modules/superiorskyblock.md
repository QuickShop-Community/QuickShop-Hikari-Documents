This module added [SuperiorSkyBlock](https://www.spigotmc.org/resources/87411/) supports.

## How does it work?

岛屿拥有者将可自由管理岛屿上的商店，且在对应玩家解除合作时能自动移除他们开设的商店。

## 配置

```yaml
owner-create-only: false
delete-shop-on-member-leave: false
```
